# Error Correction Exercise Generator

正しいCプログラムから、誤り修正課題HTMLと実行結果ベースの正誤判定を作る最小プロトタイプです。

## できること

- 正しいCプログラムとテスト入力を受け取ります。
- 正しいCプログラムを実行して、各テスト入力の期待出力を作ります。
- [rules/error-rules.json](/Users/sakamotoharuki/Documents/Codex/figure5/rules/error-rules.json) に定義した誤り混入ルールから、適用可能なものを選んで黄色の編集可能ブロックとして埋め込みます。
- 最大誤り数とシードを指定して、同じプログラムから異なるバリエーションを生成できます。
- `解答` ボタンで、編集後のCコードをコンパイルし、生成済みの期待出力と比較します。

## 起動

Cコンパイルを行うため、ローカル判定サーバを使います。

```sh
node server.js
```

ブラウザで `http://localhost:8001` を開いてください。

テスト入力は `---` だけの行で区切ります。
